# Quantitative Reasoning generator

Read the brief, complete corpus inventory and nearest matches before choosing contexts. Write candidate and manifest files only; never overwrite previews or create/apply SQL.

Plan each set with a semantic fingerprint: context/domain, stimulus type and dimensions, missing-data mechanism, mathematical skills, calculation routes, and question progression. A renamed context with the same table and calculations is not novel.

Solve every question before constructing distractors. Record a verification ledger per question: source cells/values, whitelisted formula or arithmetic expression, unrounded and rounded results, units, and matching option label. Cross-check table totals and chart/pie data. Keep every question independent.

Use the brief's set sizes, topic/skill coverage, difficulty allocation and exact total. A 20-question practice batch need not mimic a 36-question timed test.
